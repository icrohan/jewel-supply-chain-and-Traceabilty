# jewel-supply-chain-and-Traceabilty

# 💎 Jewel Supply Chain Traceability using Blockchain

## 🚀 Overview

This project implements a **blockchain-based traceability system** for the jewelry supply chain using Ethereum. It ensures **transparency, authenticity, and fraud prevention** by tracking products from manufacturer to consumer.

---

## 🧠 Problem Statement

The traditional jewelry supply chain suffers from:

* ❌ Counterfeit products
* ❌ Lack of transparency
* ❌ No reliable way to verify authenticity
* ❌ Complex multi-level distribution

---

## 💡 Solution

This project uses **blockchain technology** to create a **secure and tamper-proof system** where every transaction is recorded and cannot be altered.

The system tracks the product lifecycle across three main roles:

* 🏭 Manufacturer
* 🏬 Retailer
* 🧑‍💼 Consumer

---

## 🏗️ System Architecture

```text
Manufacturer / Retailer / Consumer
            ↓
        Frontend UI
            ↓
    Smart Contracts (Solidity)
            ↓
   Ethereum Blockchain (Ganache)
```

## 🔄 Workflow

### 1. Manufacturer

* Registers product on blockchain
* Adds product details

### 2. Retailer

* Receives product

### 3. Consumer

* Verifies product authenticity

## 🛠️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/icrohan/jewel-supply-chain-and-Traceabilty.git
cd jewel-supply-chain-and-Traceabilty
```

---

### 2. Install dependencies

```bash
npm install
```

---

### 3. Start Ganache

* Open Ganache GUI
* Start a new workspace
* Copy RPC URL

---

### 4. Configure MetaMask

* Connect MetaMask to Ganache network
* Import account using private key

---

### 5. Compile contracts

```bash
truffle compile
```

---

### 6. Deploy contracts

```bash
truffle migrate
```

---

### 7. Run the project

```bash
npm start
```
